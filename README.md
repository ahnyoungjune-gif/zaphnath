# 태합입지전 4 v215 메시지 시험 패치

[패치 ZIP 다운로드](https://github.com/ahnyoungjune-gif/zaphnath/raw/refs/heads/main/taikou4/Taikou4_v215_msg_patch_only.zip)

메시지 파일 25개와 설치 설명, 정적 검사 결과를 포함합니다. 실행 파일과 원본 백업은 포함하지 않습니다.

## 설치

1. 기존 `Game/msg` 폴더를 백업합니다.
2. ZIP을 내려받아 압축을 풉니다.
3. `GAME_ROOT/msg`의 파일 25개를 실제 게임의 `Game/msg`에 복사합니다.
4. 제공받은 v213 `Taikou4.exe`와 기존 `START.EXE`를 사용합니다.

이 패치는 Windows 실행 검증 전 시험판입니다. 정적 검사 통과가 실행 성공을 입증하지는 않습니다. 이벤트·별도 UI·인명·지명까지 완성된 한글판은 아닙니다. 문제가 있으면 설치 전에 백업한 `msg` 폴더를 복원합니다.
